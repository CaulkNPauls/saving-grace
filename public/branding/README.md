# /public/branding

Place the real Saving Grace logo file here as:

```
saving-grace-logo.png
```

(or update the path in `src/components/Logo.tsx` if you use a different
filename or an SVG). This is the actual supplied jackalope/antler artwork —
do not replace it with a generated or redrawn substitute.

The homepage Hero displays this logo once, at full size. Do not add
additional copies of the full logo elsewhere in the site.
